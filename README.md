# Authentic Shits — site boutique

Site statique (HTML/CSS/JS, sans build). Le paiement passe par Shopify (voir `SHOPIFY.md`).

- Catalogue : `js/products.js`
- IDs Shopify : `js/shopify-variants.js`
- Boutique Shopify : `js/config.js`

Lancer en local : `python3 -m http.server 4173` puis http://localhost:4173
